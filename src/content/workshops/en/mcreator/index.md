In this workshop, children aged 9 and up learn how to create their own small mod for Minecraft — with no prior programming experience! Using the MCreator tool, we use simple code blocks to create new items, creatures, or game mechanics. Everything works visually and playfully.

Learning Goals:
* Participants can navigate and use MCreator
* Participants can add new mod elements to the game
* Participants can test and play their mods

Participants need:
* Laptop or desktop PC
* The "MCreator" app installed
* [CoderDojo Schöneweide Guide](https://coderdojo-schoeneweide.de/docs/anleitung-mcreator.pdf)
